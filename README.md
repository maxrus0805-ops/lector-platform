Учебный проект, представляющий собой платформу для подбора лекторов, спикеров и тренеров для физических и юридических лиц. Реализован на основе макета Figma.

## Стек и версии
* **React** версия 19.3.1 
* **ReactDOM**
* **Vite** версия 8.3.4
* **CSS Modules**
* **Нативный JavaScript (ES6+)**

## Команды для установки и запуска

Для запуска проекта на локальной машине выполните следующие команды:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/maxrus0805-ops/lector-platform.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd lector-platform
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
5. Откройте в браузере адрес, указанный в терминале (обычно `http://localhost:5173`).

## 🗂 Где лежат данные и роутинг

* **Данные:** Вся информация о лекторах (ФИО, стаж, образование, списки дисциплин и тем, тарифы) хранится в файле `src/data/lecturers.js` в виде массива объектов. Если вам нужно изменить данные, редактируйте этот файл.
* **Роутинг:** Так как использование `react-router-dom` запрещено условиями задания, маршрутизация реализована вручную через History API. 
  * Логика маршрутов (какой URL какую страницу рендерит) находится в `src/router/routes.js`.
  * Сам контекст навигации (функции `navigate`, `path`) и обработчик кнопки "Назад" в браузере находятся в `src/router/Router.jsx`.
```
